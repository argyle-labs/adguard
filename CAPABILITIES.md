# adguard — service backend + tool surface

Pure-Rust plugin (**no bash/compose/provision scripts**) that drives an
already-running AdGuard Home instance over its `/control/*` REST API. HTTP Basic
auth; the client rides orca's `http.request` capability (`delegated-http`), so
the plugin links no reqwest/rustls.

One binary registers **two facets** on the `Plugin` builder: a `ServiceBackend`
(the generic `service.*` lifecycle) and the `adguard.*` `#[orca_tool]` surface.

## Tools
- [x] `adguard.{list,detail,create,update,delete}` — endpoint-registry CRUD
      (generated by `#[endpoint_resource]`; `routes` fallback list + `#[secret]`
      password in the abstract secrets domain)
- [x] `adguard.status` — version + running/protection flags (`GET /control/status`)
- [x] `adguard.rewrite.list` — list DNS rewrites (`GET /control/rewrite/list`)
- [x] `adguard.rewrite.add` — add one rewrite (`POST /control/rewrite/add`)
- [x] `adguard.rewrite.delete` — delete a (domain, answer) rewrite (`POST /control/rewrite/delete`)
- [x] `adguard.rewrite.set` — idempotent upsert: point a domain at an answer
      (delete-then-add; AdGuard has no direct update verb)

## Service backend (`service.*`)
- [x] declares runtimes (docker/podman/lxc/vm), capabilities
      (deploy/backup/restore/configure/status), default port, and `data_paths`
      for the generic pluggable backup
- [ ] `workload_spec` / `configure` / `status` — planned (currently
      `ServiceError::unimplemented`)

## Provided generically by orca (NO code here)
- endpoint reachability resolution (`route::resolve_reachable` over the `routes` list)
- secret storage/resolution (`adguard.<endpoint>.password`)
- the CLI / REST / MCP surfaces over every `adguard.*` tool
